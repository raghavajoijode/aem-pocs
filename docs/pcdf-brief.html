AEM POC · PCDF

One promotion. One winner. No page campaigns.

Authors write locale-scoped promotions as Content Fragments. Apps ask Publish for the winner — or an explicit empty result.

Problem

Campaigns should not wait on developers or page wiring.

  • Today, launching promo copy often means a ticket, a component, or a page property.
  • Consumer apps need a stable contract: locale + context in, one JSON payload out.
  • If nothing qualifies, say so. Do not invent another language or a default banner.
Authoring

Marketers stay in the fragment editor.

  • Open a locale folder under DAM: en-us, en-gb, fr, it, de, hi.
  • Create one Programmatic Promotion fragment — not a variation set, not a page.
  • Set copy, calendar dates (no time), targeting lists, status, and priority.
  • Publish. Drafts never win, including on Author preview.
  • Home, PDP, and mobile reuse the same fragment by calling the API.
  • No campaign field on the page.
Locales

Folder name is the locale code.

Lowercase, hyphenated. locale=en-us reads /content/dam/aem-poc/pcdf/en-us. en_US does not match. Unknown ja is no-match, not French.

The same promotionId may exist in Hindi and US English; uniqueness is per folder.

Decision

Published → active → in date → targeting → highest priority.

Ties go to the lexicographically lower id. Publish always uses today. Preview date is Author-only and is rejected on live.

Hand-off

Install PCDF without the rest of the site.

mvn clean install -pl pcdf -am -PautoInstallPcdf

Repeat with -PautoInstallPcdfPublish. Zip identity: com.aem.poc.pcdf. Default core and /apps/aem-poc are not in that zip. Site all embeds the same zip for a combined install.

Author vs Publish

Preview is a signed-in Author tool.

  • Author without a session: 401. Publish: anonymous GET.
  • Author previewDate=2026-10-15 on en-us: pcdf-future.
  • Same preview query on Publish: 400 preview_not_allowed.
Ask

Prove it in one install pass.

Install only the PCDF zip, author or open a fragment, hit Publish, confirm winner vs no-match vs preview. Full scenario list: docs/pcdf-executive.md.
